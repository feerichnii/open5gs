# SBI ProblemDetails — cause values (lab)

Constants: `lib/sbi/ogs-sbi-cause.h`.

## NRF (TS 29.510 §6.1.6.3)

- `INVALID_QUERY_PARAM`, `MANDATORY_IE_MISSING`, `MANDATORY_IE_INCORRECT`, `MANDATORY_QUERY_PARAM_MISSING`

## UDM (TS 29.503 §6.1.7.3)

- `USER_NOT_FOUND`, `DATA_NOT_FOUND`, `UNSUPPORTED_RESOURCE_URI`, `AUTHENTICATION_REJECTED`, `SERVING_NETWORK_NOT_AUTHORIZED`

## AMF (TS 29.518 §6.1.7.3)

- `CONTEXT_NOT_FOUND`, `UE_NOT_REACHABLE`, `TEMPORARY_REJECT_REGISTRATION_ONGOING`

## SCP (TS 29.500 §6.10.8)

- `NF_DISCOVERY_FAILURE`, `NF_SELECTION_FAILURE`, `TARGET_NF_NOT_REACHABLE`, `NRF_NOT_REACHABLE`, `SCP_INTERNAL_ERROR`

All `ogs_sbi_server_send_error()` calls in NRF, SCP, AMF, and UDM should pass a non-NULL `cause` for 4xx/5xx where TS defines one.
